# Habit Tracker

A simple and effective habit tracker to help you build and maintain good habits.

## Features

- Track daily habits
- Visualize your progress
- Easy to use interface

## Live Demo

[View the Habit Tracker Live](https://health-tracker-app-eight.vercel.app/)

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Amitava-Roy/health-tracker-app.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:

   ```bash
   npm start
   ```
